# Бэнг!

Неофициальная цифровая адаптация классического карточного BANG! для Zarya Boardgames. Отдельный проект; файлы Рокугана не изменяются.

## Запуск на Windows

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd run serve
```

Откройте http://localhost:3003. В локальной партии можно играть за всех участников или передавать устройство. В сетевой комнате каждый занимает собственное место. Данные сетевых партий хранятся в `data/matches`; локальные партии — в браузере.

## Управление

- Нажмите карту руки, выберите игрока на столе, затем «Использовать».
- Для кражи/сброса выберите игрока и нажмите на его рубашку руки либо открытую карту.
- Ответьте картой руки, проверкой Бочки или кнопкой принятия урона.
- Лупа открывает карту и русское описание. Роль и руку можно скрыть.
- «Исправить действие» включает ручной режим для всего стола: изменение жизней и самородков, перемещение карты, добор и отмена последнего действия. Отмена работает и после победного действия. Уже увиденная информация не становится неизвестной.

## Проверка

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run test:platform
# При запущенном сервере:
node scripts/full-cycle.cjs
```

Автоматические партии в тестах проверяют сохранность всех карт. Сетевой сценарий проходит полный цикл и проверяет скрытые данные, отмену выстрела и жизней у всех клиентов, а также отмену финала. Результаты сохраняются в `docs/qa`.

## Этапы

База: 80 карт, 16 персонажей, 4–7 игроков. В лобби можно отдельно включить **Додж-Сити**: 120 карт вместе с базой, 31 персонаж, 3–8 игроков. Зелёные карты сначала выкладываются на стол; их эффект доступен начиная со следующего хода. Для карт с оплатой выберите карту действия, затем дополнительную карту руки. Новые способности выбираются через руку и игроков на столе.

В лобби также отдельно включаются **Полдень** (13 событий) и **За пригоршню карт** (15 событий). Можно сочетать их с Додж-Сити. При включении обеих событийных колод используются 12 случайных обычных событий и одна случайная финальная карта. Первое событие открывается перед вторым ходом первого игрока. Активное событие показано слева от стола; нажатие увеличивает карту и открывает русское описание.

**Долина теней** включается отдельным переключателем: 16 карт и 8 персонажей с изображениями издателя. Вместе с базой и Додж-Сити — 136 карт и 39 персонажей. Поддержаны ответный огонь, спасение с приватным выбором награды, покер, веерный огонь, призраки и новые способности. Для Эвелин выберите цели на столе до добора; для Прицеливания — дополнительный Бэнг!; для Веерного огня — две подсвеченные цели.

**Дикий Запад** — отдельный переключатель с 10 событиями и 8 персонажами. Колода меняется после Дилижанса или Уэллс-Фарго и работает одновременно с событиями круга. Добавлены Большой Спенсер, Флинт Вествуд, Гэри Лутер, Грегори Дек, Джон Пейн, Ли Ван Клифф, Терен Килл и Юл Гриннер. Вместе с базой, Додж-Сити и Долиной теней — 47 персонажей. Обмен Флинта и повтор Ли выполняются выбором карты руки и цели на столе; две способности Грегори можно оставить или заменить в начале хода. Молчанка учитывается по кнопке «Я заговорил»: приложение не слушает разговоры. Для Леди Розы применяется рекомендованное FAQ ограничение цепочки обменов числом живых игроков.

**Золотая лихорадка**: 24 карты отдельной колоды снаряжения, 8 персонажей, самородки и лавка из трёх предложений. Снаряжение открывается нажатием на карту; цели эффектов выбираются на самом столе. Пиво можно обменять на самородок вместо лечения. Постоянное снаряжение показано у владельца; оплатить его сброс можно через саму карту. Вместе с предыдущими наборами — 55 персонажей, 136 игровых карт и 24 карты снаряжения.

**Теневые стрелки** — самостоятельный переключатель в лобби. Выбывшие возвращаются на свой ход без жизней, сохраняют золото и уходят после хода. Теневой ренегат выбирает сторону по открытым ролям автоматически.

**Вооружён и опасен**: 28 карт, 8 персонажей, 32 общих заряда и опасные карты. Заряды выбираются через персонажа и карты на столе; доступны ручная корректировка и отмена.

**Большое ограбление поезда**: 16 карт основной колоды, 16 вагонов, станции, локомотивы и 8 персонажей. Покупка вагона, стоимость станции, ограбления и дополнительные ходы автоматизированы.

**Легенды**: 16 легендарных версий базовых персонажей и 16 подвигов; слава, похвальба и превращение в легенду. При включении используются только 16 базовых персонажей, не более 7 игроков. Остальные колоды дополнений можно смешивать.

**Промокарты**: Энни Версари, Клаус Святой, Джонни Киш, Дядя Уилл, Эмилиано и два события — Наручники и Новая личность. Уникальный контент сборников The Bullet!, Dynamite Box и Most Wanted включён без повторов. Reloaded содержит аксессуары; BANG! Duel и версия с кубиками — отдельные игры.

Все переключатели находятся в лобби. Без «Легенд» общий пул — 76 персонажей; общая игровая колода — 180 карт, отдельно вагоны, снаряжение и события. Совместимость неоднозначных сочетаний и результаты проверок записаны в [аудите](docs/qa/RELEASE-AUDIT.md) и [разработке](docs/DEVELOPMENT.md).

Полная проверка Золотой лихорадки: `TEST_GOLD=1`, `TEST_SHADOWS=1`, `TEST_DODGE=1`, `TEST_VALLEY=1`, `TEST_WILDWEST=1`, `TEST_EVENTS=highnoon,fistful`, `TEST_PLAYERS=4` или `8` для `scripts/full-cycle.cjs`. В PowerShell задавайте переменные через `$env:TEST_GOLD="1"` и аналогично остальные.

## Zarya

Node.js 22+, одна служба для HTML, API boardgame.io и Socket.IO. Игра: `bang-boardgame`. Dockerfile и compose.yaml запускают службу с постоянным хранилищем. Перед использованием Compose задайте `PUBLIC_URL` и `PLATFORM_SECRET` по `.env.example`. Подключение в каталог, DNS и общий reverse proxy выполняет владелец платформы. `deploy.sh` требует закрытый репозиторий Zarya; самостоятельного импорта ZIP не выполняет. Docker в текущей среде не проверялся.


## Проверка полной сборки

`npm.cmd run check`, `npm.cmd test`, `npm.cmd run build`.
После запуска сервера: `node scripts/all-sets-network.cjs`; затем `$env:TEST_LEGENDS="1"` и повтор той же команды. Сетевой тест создаёт отдельную проверочную комнату.
